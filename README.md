# Artbid
This project is a full-stack art marketplace. The first part of the app is a marketplace for sellers and buyers to upload and browse art images. The second part is the admin panel, which shows AI model performance, a UI to rate AI tagging and image descriptions, the dashboard, and app settings.
The frontend is built with TypeScript and Next.js, and the backend is a Python codebase with FastAPI, PostgreSQL, pgvector, Redis, and AWS S3.
